# 📊 Project 9 — Data Analysis & Visualization

> 🚀 A menu-driven Python project for data analysis, data cleaning, statistics, and visualization.

---

## 🌟 About The Project

**Project 9** is a Python-based **Data Analysis & Visualization Program** built using a `DataAnalyzer` class.

This project allows users to load a CSV dataset, explore data, perform DataFrame operations, handle missing values, generate descriptive statistics, and create different types of visualizations.

---

## ✨ Features

📂 **Load Dataset**  
Load CSV datasets using Pandas.

🔍 **Explore Data**  
View first rows, last rows, column names, data types, and basic information.

🧮 **DataFrame Operations**  
Perform filtering, sorting, column selection, and calculated-column operations.

🧹 **Handle Missing Data**  
Find, fill, drop, and replace missing values.

📈 **Descriptive Statistics**  
Calculate:
- Mean
- Median
- Standard Deviation
- Variance
- Summary Statistics

📊 **Data Visualization**
Create:
- Bar Plot
- Line Plot
- Scatter Plot
- Pie Chart
- Histogram
- Stack Plot
- Box Plot
- Heatmap

💾 **Save Visualization**  
Save generated graphs as image files.
