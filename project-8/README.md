# 🚀 NumPy Analyzer (Python)

A simple Python project that demonstrates the use of **NumPy arrays** and **data analysis operations** through a menu-driven application.

---

## 📌 Features

### 🏗️ Array Creation

* Create 1D Array
* Create 2D Array
* Create 3D Array

### 🎯 Indexing & Slicing

* Access elements using indexing
* Indexing for 1D, 2D & 3D arrays
* Slice arrays using start:end ranges
* Index validation

### 🧮 Mathematical Operations

* Addition
* Subtraction
* Multiplication
* Division
* Dot Product

### 🔗 Combine & Split Arrays

* Combine two arrays
* Split an array into multiple arrays
* Uses NumPy concatenation and array splitting

### 🔍 Search, Sort & Filter

* Search for a specific value
* Sort array values
* Filter values based on a minimum value

### 📊 Aggregates & Statistics

* Sum
* Mean
* Median
* Standard Deviation
* Variance
* Minimum
* Maximum
* Percentile
* Correlation
